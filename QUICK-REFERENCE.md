# MN EDU HELP - Quick Reference Card 📇

## 🚀 Quick Start
1. Open Google Sheet with MN EDU HELP installed
2. Look for "MN EDU HELP" in menu bar
3. Select features from dropdown menus

## 🎨 Menu Structure

### 📚 Main Menu
- **Dynamic content menus** (created by admin)
- **Utility** - Tools for content manipulation
- **Page Layout** - Print and format controls
- **Admin** - Management features (admin only)

## 🎯 Common Tasks

### Create Practice Worksheet
```
1. Select content from menu
2. Click: Utility → Fill in Blanks
3. Click: Utility → Mosaic Coloring
4. Click: Page Layout → Page Setup
5. Print!
```

### Share with Parents
```
1. Select content from menu
2. Click: Utility → Share
3. Choose format (PDF/Excel/JPEG)
4. Click: Get Link
5. Copy and send via WhatsApp/SMS
```

### Create Different Versions
```
1. Load original content
2. Click: Utility → Magic Shuffle
3. (Content is now different order)
4. Create multiple versions easily!
```

### Add New Content (Admin Only)
```
1. Click: Admin → Add New Menu
2. Fill in the form:
   - Parent: root (or existing menu)
   - Name: Your menu name
   - Category: words/numbers/tables/pictures
   - Content: Your educational content
3. Click: Add Menu
```

## 🎨 Features at a Glance

### 📝 Fill in Blanks
- **What:** Removes 40% of content randomly
- **When:** Creating practice worksheets
- **Preserves:** Headers, footers, formatting

### 🔀 Magic Shuffle
- **What:** Randomly rearranges content
- **When:** Creating different versions
- **Preserves:** Headers, footers, cell count

### 🎨 Mosaic Coloring
- **What:** Applies rainbow colors to cells
- **When:** Making content engaging
- **Creates:** Matching background, text, and border colors

### 📤 Share
- **What:** Generates shareable links
- **Formats:** PDF, Excel, JPEG, Sheet link
- **Use:** Send to parents, students, colleagues

### ➕ Add More Content
- **What:** Appends database content
- **When:** Need additional exercises
- **Result:** Notification if no more content

## 🐛 Troubleshooting

## ⚡ Pro Tips

1. **Use Fill in Blanks first** before applying colors
2. **Make backups** before major changes (automatic, but check)
3. **Test share links** before sending to parents
4. **Create templates** for common worksheet types
5. **Use Restore** to create multiple versions
6. **Keep menus organized** with clear parent relationships
7. **Name menus clearly** for easy navigation
8. **Test on mobile** if students will use phones

## ⭐ Best Practices

### ✅ DO:
- Test before sharing with students
- Use descriptive menu names
- Keep content organized
- Regular backup checks
- Preserve original languages
- Apply colors for engagement
- Print with proper settings

### ❌ DON'T:
- Delete header/footer rows manually
- Share admin credentials
- Modify script without testing
- Ignore backup history
- Change languages of content
- Skip authorization steps
- Print without page setup
